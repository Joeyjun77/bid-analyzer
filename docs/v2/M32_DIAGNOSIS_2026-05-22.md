## 2. 진단 결과 — false positive

### 2.1 영향 범위
| 항목 | n |
|---|---|
| `is_duplicate=true` (m30 마킹) | 113 |
| `is_duplicate=false` 중 `pn_no` 중복 잔존 | **1,934 pn_no / 4,661 rows** (max 7/pn) |

→ partial UNIQUE 적용 시 4,661건 충돌로 인덱스 생성 자체 실패.

### 2.2 4,661건 분석 — **무결성 결함이 아닌 군부대 pn_no 재사용 패턴**

군부대 발주 pn_no(LNR/LNG/LPC/LMR/LPM/LPG/HCR 등)는 짧은 코드여서 **연도별 재사용**됨.

샘플 `LNR0091-1`:

|---|---|---|---|
| 2012-12-12 | 제7021부대 | 176,337,939 | 100.27 |
| 2016-12-14 | 제7021부대 | 151,486,000 | 98.67 |
| 2019-12-11 | 제7021부대 | 34,564,980 | 99.23 |
| 2021-09-10 | 수도기계화보병사단 | 82,871,000 | 100.26 |
| 2023-06-21 | 수도기계화보병사단 | 96,943,000 | 100.70 |
| 2025-06-17 | 수도기계화보병사단 | 67,420,000 | 100.57 |

→ od/ag/ba/ar1 모두 다른 정상 다중 데이터.

### 2.3 기존 무결성 — 이미 충분
| 인덱스 | 정의 |
|---|---|
| `bid_records_dedup_key_key` | UNIQUE on `dedup_key` (md5 of `pn + ag + od + ba`) |
| `idx_bid_records_pn_no` | btree on `pn_no` (non-unique, 검색용) |
| `idx_bid_records_is_duplicate` | partial WHERE `is_duplicate=true` |

→ **동일 공고(pn+ag+od+ba) 단일 INSERT는 이미 보장 중**. m30 113건은 다른 종류의 중복 (Z-DETAIL과 별개 후속 분석 가치 있음).
