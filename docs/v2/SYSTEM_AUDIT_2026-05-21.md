## 1. 요약 (3줄)

1. 현재 예측 시스템은 **4종 (V6 predict_v6 / V2 Mode B / V2 Mode A / agency-floor V1)** 이 동시 가동·동시 노출되는데, 각각이 **다른 공간에서 다른 목표를 예측**한다. 사용자의 "낙찰사정율 예측이 맞나" 의문은 4종이 사용자 화면에서 명확히 구분 안 되는 데서 비롯됨.
2. V2 마스터플랜은 "MAE 1차 KPI 지위 폐기"를 **전 영역에 일괄 적용**했으나, 영역별 gap_p90(1위 산포)가 한전 0.0060·지자체 0.0209처럼 **사정률 예측 정확도(MAE)가 곧 1위 적중에 가까운 영역**에서는 V6 사정률 예측이 여전히 본질 기여. Mode A WIN-zone은 군시설(gap_p90 0.7993)에만 의미 있고, 다른 영역은 Mode B 하한 통과(안전망) + V6 사정률(점추정) 조합이 더 적합할 가능성.
3. 라운드 8~14의 반복 루프는 본질적으로 **B2 운영 안정화 + 4주 PASS 자연 누적 대기**가 본 작업인데, 그 동안 minor fix만 라운드 단위로 누적되어 사용자에게 "본질 진행 없음" 인상. 앞으로는 **본질 결정 (Mode A 전 영역 확장 가능성 / V6 retire 영역별 분리 / UI 결정 명확화)** 이 라운드 안에 들어와야 함.

## 2. 예측 시스템 4종 비교

| 시스템 | 예측 대상 | 출력 단위 | 입력 | UI 노출 | 자사 1위 낙찰 기여 | 현재 상태 |
|---|---|---|---|---|---|---|
| **V6 predict_v6** | 1순위 사정률(br1) 점추정 | 100-base % | at, ag, ba, ep, av, ownScore | "예측" 탭 메인 추천 | **직접** — 자사 신고 사정률 결정 입력 | 가동 중 (메인) |
| **V2 Mode B** | 자사 투찰가가 낙찰하한율을 통과할 확률 | 0~1 확률 | 자사 사정률 분포(mean, std) + fr | "🧪 V2 미리보기" 탭 | **간접** — 무효 입찰(하한 미통과) 방지 안전망 | 가동 중, KPI 측정 중 |
| **V2 Mode A** | 자사 투찰가가 WIN-zone(1위 가능 사정률 범위) 진입 확률 | 0~1 확률 | gap_p25/p50 (분포 기반) | "🧪 V2 미리보기" 탭 (군시설 한정) | **직접** — 1위 가능 범위 진입 확률 = 1위 적중 추정 | 군시설만, WARN (12.42%) |
| **agency-floor V1** | 발주사별 1위 사정률 분포 중앙값 | 100-base % | canonical_ag, cat | "🎯 발주사 하한" 탭 | **정보 표시** — V6 추천 검증·참고 | 가동 중 (정보 탭) |

### 핵심 관찰

- **V6과 V2 Mode B는 공간이 다름**: V6은 **사정률 공간**(점추정), V2 Mode B는 **통과확률 공간**(자사 신고값 → 통과 P). 같은 입력에서 다른 답 → 사용자가 "어느 게 맞는 추천인지" 혼동.
- **자사 1위를 *직접* 예측하는 건 Mode A뿐**: Mode B는 무효 입찰 방지, V6은 사정률 점추정. 1위 적중에 직접 결합되는 건 Mode A의 WIN-zone 진입확률.
- **그런데 Mode A는 군시설 한정**: 마스터플랜 §3 D2 표 기준 `gap_p90 ≥ 0.10` 조건. 한전(0.0060)·지자체(0.0209) 등은 자동으로 Mode B 영역.

## 3. 영역별 모드·적합성 재평가

마스터플랜 §3 D2 표를 기준으로 영역별 의사결정 함의를 재정리:

| 영역 | n | gap_p90 | 현재 모드 | gap이 작다는 것의 의미 | V6 사정률 정확도가 1위 적중에 충분한가 |
|---|---|---|---|---|---|
| **군시설** | 186 | **0.7993** | A (WIN-zone) | 1위 사정률 산포가 매우 큼 — 사정률만 맞춰서는 1위 어려움 | ❌ 부적합 — Mode A WIN-zone이 본질 |
| **지자체** | 349 | 0.0209 | B + 조건부 A | 1위 사정률 산포 ±0.02% — 사정률 정확도가 1위 적중에 거의 충분 | ✅ 적합 — V6 사정률 정확도가 본질 |
| **교육청** | 230 | 0.0102 | B | 1위 산포 ±0.01% — 사정률 정확도가 1위 적중에 사실상 충분 | ✅ 매우 적합 |
| **한전** | 39 | 0.0060 | B | 1위 산포 ±0.006% — V6 MAE ~0.6% 이하면 1위 적중 가능 | ✅ 매우 적합 (n 보강 필요) |
| **조달청** | 26 | 0.0019 | B + 공격성 교정 | 1위 산포 ±0.002% — 사정률 정확도가 거의 결정적 | ✅ 매우 적합 (n 보강 필요) |
| **LH** | 11 | 0.0060 | B (n 보강 후) | 산포 작음 | ✅ 적합 (n 보강 필요) |

### 시사점

- **한전·지자체·교육청·LH·조달청 = "사정률 영역"**: 1위 사정률 산포가 매우 작으므로 V6 사정률 예측 정확도(MAE)가 1위 적중에 가깝게 직결. 마스터플랜의 "MAE 1차 KPI 폐기"는 이 영역에 대해 과한 가능성 있음.
- **군시설 = "WIN-zone 영역"**: 산포가 매우 커서 사정률만으로는 1위 불가. Mode A WIN-zone이 본질. 현재 가동 중이나 WARN (12.42% / 목표 15%).
- **Mode B는 모든 영역에서 안전망**: 자사 투찰가가 무효(하한 미통과)되는 걸 막는 보조. 1위 적중과는 별도 차원.

## 4. 사용자 본질 의문에 대한 직접 응답

> "예측 시스템에 낙찰사정율 예측이 맞는 건지 모르겠어"

**답**: 영역마다 다르다.

- **한전·지자체·교육청·LH·조달청 영역**: 사정률 예측이 **맞다**. gap_p90이 0.006~0.02 수준이라 자사 신고 사정률이 1위 사정률에 가까우면 1위 적중. V6 predict_v6의 점추정 + agency-floor V1의 분포 중앙값은 자사 의사결정에 직접 기여.
- **군시설 영역**: 사정률 예측만으로는 **부족하다**. gap_p90 0.7993으로 산포가 크므로 1위 사정률 분포에 자사가 들어갈 확률(WIN-zone 진입확률) 자체가 핵심. Mode A가 본질이고, 현재 12.42%(목표 15%)로 가동.
- **공통 안전망**: 모든 영역에서 V2 Mode B는 자사 투찰가가 하한 미통과로 무효 처리되는 걸 막는 안전망. 1위 적중과는 별도 차원.

### 사용자 의사결정 흐름 (권장)

1. 신규 입찰 진입 → at(발주처 유형) 확인
2. at이 **군시설** → "V2 미리보기" Mode A 진입 → WIN-zone 진입확률 × gap 분포 보고 신고 사정률 결정
3. at이 **그 외** (한전·지자체·교육청·LH·조달청·기타) → "예측" 탭 V6 메인 추천 + "🎯 발주사 하한" 탭 발주사별 분포 중앙값 교차 검증 → 신고 사정률 결정
4. 어느 경우든 → 결정된 사정률 → 자사 투찰가 계산 → Mode B 통과확률 ≥95% 확인 (안전망)
5. → 나라장터 투찰

현재 UI는 위 흐름이 명확히 분기되지 않음. **앞으로 작업 #1: UI 결정 명확화** (다음 §6.A).

## 7. 코덱스 메타 상의 의뢰 항목

본 보고서를 라운드 N+1 BRIEF가 아닌 **메타 시스템 점검**으로 코덱스에 의뢰. 핵심 질문 5건:

1. **§3 영역별 모드 적합성 재평가에 동의하는가?** — 한전·지자체·교육청·LH·조달청 영역에서 V6 사정률 예측이 1위 적중에 본질 기여라는 분석.
2. **§4 사용자 의사결정 흐름 권장 분기가 적절한가?** — at=군시설 vs 그 외로 분기, 각각에 V6/V2 Mode A 우선 표시.
3. **§5.2 반복 루프 원인 진단이 정확한가?** — 4주 PASS 누적 대기가 본질 원인, fix-of-fix 라운드 패턴은 그 부산물.
4. **§6 작업 로드맵의 우선순위가 옳은가?** — A(UI) > D(V6 retire 정책 정정) > B(Mode A 확장 검토) > C(군시설 재측정) > E(Phase 3 #2). 라운드 N+1 BRIEF는 잠시 중지하는 게 좋은가?
