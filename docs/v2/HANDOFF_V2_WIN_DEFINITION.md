> 대상: Claude Code 세션
> 목적: "자사 낙찰"의 정확한 판정 조건 확정 + 흔한 오해 교정

> 근거: 입찰교육자료 (복수예비가격 / 적격심사 / 투찰금액 산출식)

---

## 0. 핵심 결론 — 오해 교정

> ❌ 오해: "낙찰 데이터의 1위 사정률보다 낮게 예측하면 자사가 낙찰된다"
> ✅ 정정: **절반만 맞다.** "1위보다 낮게"는 상한 조건일 뿐이고,
>          하한 조건(낙찰하한가)이 빠지면 정반대 결과(즉시 탈락)가 나온다.

입찰은 **두 경계로 둘러싸인 구간(WIN zone) 게임**이다.
가장 낮게 쓴 업체가 떨어지는 것이 이 제도의 핵심이다.

```
        탈락               WIN zone              패배
   ├──────────────┤├──────────────┤├──────────────┤
              낙찰하한가      현재 1위 투찰가
   (너무 낮음 →             (너무 높음 →
    하한 미달 탈락)           경쟁사에 밀림)
```

---

## 1. 낙찰자 결정 순서 (교육자료 6쪽 기준)

```
1. 모든 적격 업체 중 → 낙찰하한가 이상으로 투찰한 업체만 후보
2. 후보들 중 → 투찰금액이 낮은 순서로 줄세움
3. 가장 낮은 1위부터 → 적격심사(종합평점 95점) 통과하는 첫 업체가 낙찰
```

교육자료 원문: 적격심사는 "예정가격 이하 **낙찰하한율 대비 직상(直上) 최저가격**으로
입찰한 자 순으로" 심사한다.

→ 핵심: 하한선 바로 위에 가장 가깝게 붙은 업체가 1위.

---

## 2. 자사 낙찰 = 3중 조건 (동시 충족 필수)

| 조건 | 판정식 | 빠지면 결과 |
|------|--------|-------------|
| 하한 | 자사 투찰금액 ≥ 낙찰하한가 | 입찰가격 점수 미달 → 즉시 탈락 |
| 상한 | 자사 투찰금액 < 1위 경쟁사 투찰금액 | 경쟁사가 낙찰 |
| 적격 | 종합평점 95점 이상 | 차순위 업체로 넘어감 |

정식 명제:

```
낙찰하한가  ≤  자사 투찰금액  <  현재 1위 경쟁사 투찰금액
            AND  적격심사 통과
→ 자사 낙찰
```

"1위보다 낮게"만 보면 하한 조건이 누락된다.
1위보다 낮아도 낙찰하한가 아래면 탈락이다.

---

## 3. 사정률 방향 주의 — 가장 헷갈리는 부분

> ❌ 오해: "사정률을 낮게 예측 = 낙찰 유리"
> ✅ 정정: 사정률은 **예정가격을 예측하는 값**이지,
>          자사가 낮게/높게 쓰는 전략값이 아니다.

### 3.1 금액 산출식

```
자사 투찰금액 = 기초금액 × (100% + 자사예측사정률) × 낙찰하한율

낙찰하한가   = 예정가격 × 낙찰하한율
            = 기초금액 × (100% + 실제사정률) × 낙찰하한율
```

### 3.2 예측 사정률을 잘못 잡으면

```
자사 예측 사정률  <  실제 사정률
  → 자사 투찰금액 < 낙찰하한가
  → 하한 미달 → 즉시 탈락   ⚠ "낮게 쓰면 유리"의 함정

자사 예측 사정률  >  실제 사정률 (약간)
  → 하한 위에 안전하게 안착
  → 단, 너무 높으면 1위 경쟁사보다 높아져 패배
```

→ 맞춰야 할 것은 "실제 사정률 그 자체".
→ 그 실제 사정률이 복수예비가격 난수(C(15,4)=1,365) → ±0.642% 노이즈 플로어 발생.

## 4. V2 예측 시스템이 풀어야 할 진짜 문제

3중 조건을 예측 모델 관점에서 분해하면:

| 조건 | 예측 대상 | V5~V7 상태 |
|------|-----------|------------|
| 하한 | 실제 사정률(예정가격) 분포 | 다루던 일 (MAE 최소화) |
| 상한 | 1위 경쟁사 투찰 분포 | **거의 안 다룸** ← 핵심 누락 |
| 적격 | 자사 종합평점 | 사전 계산, 결정론적 |

### V5~V7이 낙찰률 5.0%에 머문 구조적 이유

```
하한을 의식해 보수적으로 씀  → 경쟁사에 밀려 패배
경쟁을 의식해 공격적으로 씀  → 하한 아래로 떨어져 탈락
```

두 경계 사이 좁은 구간을 **단일 추천값**으로 다루면 한쪽으로 치우친다.
→ V2는 이 구간을 **분포**로 다뤄야 한다.

## 5. 데이터 검증 필요 사항 (진단 쿼리 대상)

업로드되는 입찰 데이터에서 3중 조건을 실제로 재구성할 수 있는지 확인한다.

1. `bid_records`에 **낙찰자 투찰금액 / 1위 투찰금액** 컬럼이 있는가
   → 상한(경쟁) 모델링 가능 여부 결정
2. **낙찰하한율**이 건별로 저장되는가, 아니면 종목·금액대로 역산해야 하는가
   → 하한 판정 가능 여부 결정
3. 자사 투찰 결과 행에 **낙찰 여부(✓/✗) + 순위**가 있는가
   → 과거 자사 위치 재구성 가능 여부 결정

### 진단 쿼리 (Supabase MCP, project `sadunejfkstxbxogzutl`)

```sql
-- 1. bid_records 스키마 — 낙찰자/1위 투찰금액, 낙찰하한율, 순위 컬럼 존재 여부
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_name = 'bid_records'
ORDER BY ordinal_position;

-- 2. bid_details 스키마 — 경쟁사별 투찰가 존재 여부
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_name = 'bid_details'
ORDER BY ordinal_position;

-- 3. 한 입찰건당 경쟁사 row 수 — 경쟁 분포 추정 가능 표본 확인
SELECT bid_id, COUNT(*) AS competitor_rows
FROM bid_details
GROUP BY bid_id
ORDER BY competitor_rows DESC
LIMIT 20;

-- 4. WIN zone 재구성 가능성 점검 (※ 1번 결과로 실제 컬럼명 확인 후 수정 실행)
--    하한가/1위가/자사투찰가 3개가 모두 있어야 과거 낙찰 판정 재현 가능
SELECT
  COUNT(*) AS total,
  COUNT(낙찰하한가_컬럼)   AS with_floor,
  COUNT(일위_투찰금액_컬럼) AS with_top1,
  COUNT(자사_투찰금액_컬럼) AS with_own
FROM bid_records;
```

### 분기 결정

- **세 컬럼 모두 존재** → 과거 데이터로 WIN zone 진입/패배/탈락을 정확히 분류 가능
  → 경쟁 분포 데이터 기반 추정
- **1위 투찰금액 없음** → 상한 조건을 데이터로 재현 불가
  → 경쟁 모델은 "1위 = 낙찰하한가 + α" prior에서 시작, 누적 데이터로 점진 보정
- **낙찰하한율 없음** → 종목 + 금액대로 역산 (전기 8천만~3억 = 86.745% 등 교육자료 표 활용)

## 6. 낙찰 판정 의사코드 (V2 구현 참조용)

```python
def judge_outcome(own_bid, floor_price, top1_competitor_bid, own_qualified):
    """
    own_bid              : 자사 투찰금액
    floor_price          : 낙찰하한가 (= 예정가격 × 낙찰하한율)
    top1_competitor_bid  : 자사 제외 최저 적격 투찰금액
    own_qualified        : 자사 적격심사 통과 여부 (bool)
    """
    if own_bid < floor_price:
        return "탈락"          # 하한 미달 — '낮게 쓰면 유리'의 함정
    if own_bid >= top1_competitor_bid:
        return "패배"          # 경쟁사가 더 낮게 씀
    if not own_qualified:
        return "차순위_이월"    # 가격 1위지만 적격심사 탈락
    return "낙찰"              # 하한 통과 + 경쟁 우위 + 적격 통과
```

확률 버전 (V2 본 엔진):

```
P(낙찰 | X) =
    P(자사투찰 ≥ 낙찰하한가)        ← 사정률 분포에서 적분
  × P(자사투찰 < 1위 경쟁투찰)      ← 경쟁 분포에서 적분
  × P(적격심사 통과)               ← 보통 1.0

자사투찰 = 기초금액 × (100% + X) × 낙찰하한율
```
