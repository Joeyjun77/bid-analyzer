# 참여업체 사정율 점표분포표 (Dot Distribution View)

날짜: 2026-06-13
대상 파일: `src/components/ParticipantMatrixModal.jsx` (단일 파일 변경)
분류: UI 표시 전용 (Generator 아님 — 예측 로직/`opt_adj`/`pred_bias_map`/낙찰하한율 무관, `/evaluate` 면제)

## 목적
참여업체 사정율 분포 모달에서 입찰건이 많으면 숫자 매트릭스가 가로로 넓어져 가로 스크롤이 생기고
분포를 한눈에 보기 어렵다. 사정율 세로축은 그대로 유지하면서, 셀을 점(dot)으로 그려 열을 좁히고
모든 건의 분포 모양을 한 화면에서 비교할 수 있게 한다.

## 방향 (사용자 확정)
- 사정율을 **세로(행)** 로 유지 — 현재 매트릭스와 동일 방향. 가로축으로 눕히지 않는다.
- 기존 숫자 매트릭스와 **토글 전환** — 둘 다 보존. 기본 진입은 점표.

## 데이터 (변경 없음 — 기존 `buildMatrix` 그대로)
- 세로축: `matrix.buckets` (사정율 내림차순, 데이터 있는 버킷만)
- 가로축: `matrix.columns` (최근 30건, 개찰일 desc)
- 셀: `matrix.cell(pn_no, bucket)` → `{ cnt, is_win }`
- 강조 단계: `matrixLevel(cnt, matrix.colMax(pn_no))` (0=최강 … 7=약)
- 검색사 오버레이: `overlay.get(pn_no)` → `{ adj_rate, bucketKey }`

## UI 설계
### 뷰 상태
- `view` state: `'dot' | 'matrix'` (기본 `'dot'`)
- 컨트롤바에 토글 버튼 그룹 추가: `[ 점표 | 숫자 ]` (버킷 자리수 토글과 동일한 스타일)

### 점표 뷰 (신규)
- 동일한 `<table tableLayout:fixed>` 구조 재사용 — sticky 헤더/좌측열·스크롤 그대로.
- colgroup: 첫 열 52px 유지, 데이터 열 **~22px** (점 하나 폭).
- 헤더: 입찰명(`c.pn`) 줄 **제거**, 개찰일(MM-DD, `odColor`) + ★1순위사정율(소형)만. 전체 입찰명은 헤더 `title` 툴팁에 보존.
- 셀: 숫자 대신 **원형 점**.
  - 점 지름 = 강조 단계별 매핑(예: level 0→11px … level 6→5px, level 7→미표시).
  - 색: 일반 = 중립색(`C.txm` 계열), 1순위(`is_win`) = 골드 점(★ 의미 유지), 검색사(`isCompany`) = 초록 테두리(ring).
  - `cnt===0` & 비검색사 → 빈 셀.
  - 점 `title` 툴팁: 기존 셀 툴팁과 동일(`개찰일 · 사정율 · N개사 · ★/검색사`).
- 검색사 추이 행·참여합 행: 점표 뷰에서도 유지(참여합은 숫자 그대로, 좁은 열에 맞춰 폰트만 축소).

### 숫자 뷰 (기존)
- 현재 렌더 로직 그대로. 토글로 진입.

## 비목표 (YAGNI)
- SVG 캔버스/연속 축 렌더링 안 함 (테이블 셀 점으로 충분, 정렬·sticky 재사용).
- 전체 풀링/곡선 중첩 차트 안 함 (사용자가 행=사정율 표 방향 선택).
- 새 RPC/데이터 변경 없음.

## 검증
- `npx vite build` 통과.
- 표시 전용이라 MAE/evaluate 게이트 불필요.
- 수동 확인: 토글 동작, 점 크기 강조, ★/검색사 하이라이트, 가로 스크롤 해소.
