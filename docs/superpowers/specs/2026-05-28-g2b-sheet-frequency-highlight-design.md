# G2B 양식 탭 — 발주처별 낙찰하한율·사정율 재현 빈도 강조 (설계)

- 작성일: 2026-05-28
- 분류: **Evaluator** (예측 로직 무변경 → Phase 23-3 `/evaluate` 면제)
- 상태: 설계 확정(코덱스 교차검증 반영), 구현 대기

## 1. 목표

사용자가 보유한 나라장터(G2B, bidq.co.kr) 엑셀(25컬럼)의 **레이아웃을 레퍼런스**로,
기존 `bid_records` 데이터를 같은 양식으로 보여주는 **새 탭**을 만든다.
그 안에서 **발주처(기관)별로** 두 값의 재현 빈도(이전 횟수)를 글씨크기·색상으로 강조한다.

- ① **낙찰하한율(`fr`)** — 법정 하한율 (사용자가 "투찰하한율"로 호칭)
- ② **발주처사정율(`ar1`)** — 예정가격/기초금액 (100% 기준)

데이터는 기존 입찰분석기의 데이터를 그대로 활용하고, 업로드도 기존 인포21c 파서를 그대로 사용한다.
이 탭은 **읽기·표시 전용**이며 신규 DB 객체·DB 호출을 추가하지 않는다.

## 2. 배경 결정 (코덱스 협의 결과)

코덱스 교차검증에서 두 건 재설계 권고가 나왔고, 사용자 협의로 다음과 같이 확정했다.

| 쟁점 | 코덱스 판정 | 확정 |
|---|---|---|
| ar1 빈도 강조 | 🔴 추첨 준난수라 "기관이 자주 만드는 값"으로 오도 위험 | **빈도 강조 유지하되**, 표본수 `n` 병기 + "추첨 결과 관측값, 기관의 의도적 선택 아님" 캐비어트 툴팁 |
| fr 빈도 era·금액대 혼재 | 🟡 발주처 성향 아님 → `era×금액대×A값` 구성비 | **era×금액대 필터 추가**. 기본 전체, 필터로 좁히면 빈도 정밀 |
| 절대 임계값 30/10/3 | 🔴 발주처 표본편차 미반영 | 절대횟수 폐기 → **기관 내 점유율(비율) 기반 강조 + `n` 상시 노출** |
| 클라 빈도맵(DB무변경) | 🟡 채택가능 | 채택. ar1 반올림·fr 부동소수 정확일치·결측 처리에 주의 |

> 도메인 근거: 사정율(ar1)은 복수예비가 C(15,4) 추첨 결과로 이론 예측 MAE 하한 0.642%의 준난수.
> `fr`은 (era × 금액대 × A값유무)에서 결정되는 quasi-deterministic 법정값.

## 4. 아키텍처 / 위치

- 신규 파일 `src/components/G2BSheetTab.jsx` (기존 `AgencyFloorTab`/`AgencyPredictorTab` 분리 패턴 준수).
- `src/App.jsx`:
  - 탭 버튼 1개 추가 (탭 키 `"g2b_sheet"`).
  - 렌더 분기 `{tab==="g2b_sheet" && <G2BSheetTab recs={recs} />}` 추가.
- `recs`(이미 로드된 `bid_records` 전체)를 props로 전달 → DB 신규 호출·객체 **없음**.
- 색상은 `src/lib/constants.js`의 `C` 팔레트 재사용.
- 임계값·버킷 단위·색·강조 스타일은 **파일 상단 상수 블록**으로 분리(조정 용이).

## 5. 데이터 흐름 / 빈도 계산

1. 탭 진입 → **발주처 검색/선택**(기존 콤보박스 UX) + 보조 필터: **업종(`cat`) · era · 금액대(S1~S5)**.
2. `useMemo`(키: 선택 발주처 + 필터)로 해당 기관 행 추출 후 빈도맵 계산:
   - `freqFr: Map<fr값, n>` — `fr`을 **소수 3자리 반올림 키**로 정확일치 집계.
   - `freqAr1: Map<0.1% 버킷, n>` — 버킷 = `Math.round(ar1*10)/10`.
   - 빈도 집계에서 `is_excluded===true` 행 제외(calcStats 관례). ※ `is_duplicate`는 클라 페치 컬럼(`BID_RECORDS_COLS`)에서 제외되어 있어 런타임 가드 불가 → 미적용(구현 시 死코드 제거됨).
   - 집계 키는 `canonical_ag` 우선(없으면 `ag`) — 본사·지역본부 혼선 방지.
3. 각 행 렌더 시 그 행의 `fr`/`ar1` 값을 맵에서 조회 → **기관 내 점유율**(`n / 기관표본수`)로 강조 강도 산출.
4. 상단 **요약 패널**:
   - 낙찰하한율: 자주 나온 값 TOP3 `(n)`.
   - 사정율: 자주 나온 값 TOP3 `(n)` + **평균±표준편차 분포대** + 표본수.

## 6. 강조 인코딩

공통: 강조는 **기관 내 점유율 기반**(절대횟수 아님), 셀 옆 `(n)` 배지로 "이전 횟수" 상시 노출.

### 6.1 낙찰하한율 `fr`
- 점유율 상위(예 ≥40%): 굵게 700 + `C.gold`(#d4a834) + 15px
- 중간(15~40%): 600 + `#5dca96`(틸) + 13px
- 낮음(5~15%): normal + `C.txt` + 12px
- 희귀(<5% 또는 n≤2): 연한 `C.txd` + 12px
- era/금액대 필터 적용 시 빈도가 해당 밴드 기준으로 재계산.

### 6.2 발주처사정율 `ar1`
- `fr`과 동일한 점유율 단계로 빈도 강조(사용자 선택: "빈도 유지").
- **단, 정직 라벨 필수**: 셀/요약에 hover 툴팁 — "추첨 결과 관측값(복수예비가 C(15,4)), 기관의 의도적 선택 아님" + `n` 병기.
- 요약 패널에 평균±σ 분포대를 함께 노출해 빈도의 과대해석 방지.

## 7. 필터 · 정렬 · 성능 가드

- **발주처 미선택 시 전체(6.5만) 렌더 금지** → "발주처를 선택하세요" 안내 + 빈출 발주처 칩.
- 선택 기관 행 수 >500 → 페이지네이션(`PAGE` 상수/기존 패턴 재사용).
- 정렬: 개찰일 desc 기본 + 헤더 클릭 정렬(`SortTh` 재사용 가능 시).

## 8. 엣지 케이스 / 정확성

- `fr`/`ar1` null → 강조 없이 "—".
- `ar1` 단위 혼재(0%기준)는 `toRecord`의 `_normRate`로 이미 100기준 통일 저장됨 → 추가 처리 불필요.
- `fr` 부동소수 비교는 반올림 키로 정확일치 보장.
- 동일 발주처명/ canonical 분기 → `canonical_ag`로 집계.

## 9. 검증 / 배포

## 10. 비목표 (YAGNI)

- DB VIEW/RPC 신규 생성(접근법2) — 데이터가 이미 클라에 있어 과설계.
- 자사 컬럼(자사 사정율/입찰가/순위) 채우기 — bid_records에 없음.
- 사정율 예측·추천 변경 — 본 탭은 표시 전용.

## 11. 미해결 / 추후

- 강조 점유율 임계값(40/15/5%)·ar1 버킷(0.1%)은 초기값, 실사용 후 튜닝.
- `fr` 빈도를 era/금액대 자동 분할 표시(필터 외 기본 분할)로 확장할지 여부.
